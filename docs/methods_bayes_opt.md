## Bayesian parameter optimisation

To complement the exhaustive grid search over discrete half-window ($h_w$) and enrichment-window ($e_w$) values, a Bayesian optimisation (BO) alternative was implemented for Discovery-mode parameter selection. For each target RBP, the per-RBP AUROC objective — identical to that used in the grid search — was treated as an expensive black-box function over a continuous two-dimensional search space ($h_w \in [5, 35]$, $e_w \in [30, 300]$, rounded to integer nucleotide positions before evaluation).

An initial design of eight points was drawn by Latin hypercube sampling to cover the search space with low-discrepancy coverage. At each subsequent iteration, a Gaussian process (GP) surrogate was fitted to all observations collected so far. The GP employed a Matern-5/2 covariance kernel with automatic relevance determination (ARD), providing independent length-scale parameters for $h_w$ and $e_w$, and kernel hyperparameters were optimised by marginal likelihood maximisation. The Expected Improvement (EI) acquisition function was then maximised over the search space by multi-start L-BFGS-B optimisation from 1,000 random initialisations, with the best candidate rounded to integer coordinates and evaluated through the full pipeline (motif enrichment, MARS-format conversion, association scoring, AUROC computation). This sequential design–evaluate–update loop was run for 30 iterations, yielding a total budget of 38 objective evaluations per RBP.

Bayesian optimisation was run independently for each RBP in the reference panel, mirroring the per-RBP framing of the grid search. Per-RBP random seeds were derived deterministically from a master seed to ensure full reproducibility. Results — including the full evaluation trace and fitted GP surrogate — were logged to the existing JSON manifest for crash-safe resumption.

Across 28 RBPs in both panels (15 HepG2, 13 K562), BO achieved a mean AUROC of 0.705 compared to 0.745 for the grid search (mean $\Delta$ = $-0.039$ $\pm$ $0.108$), with 28/28 RBPs finding optima at parameter combinations outside the grid's discrete set. Grid search outperformed or matched BO in 19/28 cases (68%). The mean wall-time per RBP was approximately $560$ min for BO versus $\sim50$ min for grid search ($\sim10\times$; 38 vs 20 evaluations).
